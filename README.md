# Mini B2B RFQ Marketplace

A production-ready mini B2B Request for Quotation (RFQ) marketplace web application connecting Buyers and Suppliers.

## Overview
Buyers create, edit, and close RFQs. Suppliers browse open RFQs and submit quotation bids. Built with React (Vite) + Express.js + MySQL using secure session-based authentication.

## Stack
- **Frontend**: React 18, Vite, Bootstrap 5, React Router, Axios
- **Backend**: Node.js, Express.js, raw parameterized SQL (mysql2)
- **Database**: MySQL (3NF normalized)
- **Authentication**: express-session, MySQL session store, bcryptjs
